# Flow Connector

Connect Flow image & video creation to any coding agent.
no API key 
Queue prompts, generate them in batches on [Google Flow](https://labs.google/fx/tools/flow),
and have every file downloaded for you — driven from Claude Code, Cursor, Codex,
Windsurf, Gemini, or the extension's own side panel.

It runs in **your** browser, on the Google account you are already signed into.
Nothing is proxied through a server, which is why generation costs nothing.

## What it does

- **Images in batches** — Nano Banana Pro, 2 and Lite
- **Video in batches** — Omni Flash and Veo 3.1 (Lite / Fast / Quality)
- **Every mode** — text-to-image, image-to-image, text-to-video, first-frame /
  last-frame, ingredients-to-video, extend, merge
- **Auto-download** — results land in your downloads folder, named, not lost in a tab
- **Agent bridge** — one paste sets it up in whatever coding agent you use

## Install

The Chrome Web Store and Edge Add-ons listings go live shortly. This repo is the
support channel and the home of the agent skill and docs — the extension itself
is distributed through the stores.

## Support

Something broken, or a Flow interface change that stopped automation working?
[Open an issue](https://github.com/srijan-kaiwart/flow-connector/issues/new) —
the extension's Help tab fills most of the report in for you.
